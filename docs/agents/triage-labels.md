# Triage 标签

技能以五个规范 triage 角色为语言。此文件将角色映射到本仓库 issue tracker 实际使用的标签字符串。

| 角色（mattpocock/skills） | 本仓库标签 | 含义 |
| ------------------------ | ---------- | ---------------------------------------- |
| `needs-triage`           | `needs-triage` | 维护者需要评估此 issue |
| `needs-info`             | `needs-info`   | 等待报告者补充更多信息 |
| `ready-for-agent`        | `ready-for-agent` | 规格完整，可供 AFK agent 处理 |
| `ready-for-human`        | `ready-for-human` | 需要人工实现 |
| `wontfix`                | `wontfix`     | 不予处理 |

当技能提到某个角色（如"应用 AFK-ready triage 标签"）时，使用本表对应的标签字符串。

需要覆盖默认命名时编辑右列，使其匹配你实际使用的词汇。
