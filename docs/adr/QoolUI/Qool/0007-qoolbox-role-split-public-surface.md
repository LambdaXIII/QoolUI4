# QoolBox 组件职责划分：control 公开（可替换/共享）+ 变体注入

QoolBox 公开 `control` 属性（类型 `QoolBoxShapeControl`，见 ADR-0004）——可替换/共享：宿主可注入自己的 control（兼容类型），多个组件可共享同一 control（无需分别计算）。`pCtrl`（内部 SmartObject，Component 容器）与 control 分离——pCtrl 纯内部，不暴露。变体 `OctagonShape`/`OctagonCurvedShape`（原 OctagonRoundedShape 改名，对齐 settings.curved；配套 OctagonRounded*External/InternalShapePath 同步改名）是低级 API 组件：`required property QoolBoxShapeControl control`——消费整个 control（点/space/settings），不持有几何——独立使用不自洽是刻意的（低级组成件定位）。QoolBox 默认 wiring：自建 `QoolBoxShapeControl`（target: root）+ `QoolBoxSettings`（QML 类型，Style 默认），`control.settings` 绑定 `root.settings`——宿主替换 settings 实例时绑定重挂（多层级对象替换不破坏绑定链路）。QoolBox 公开 `*Space` 四属性（转发 control）；同系组件（QoolBGBox 等）覆盖同名属性是期望行为（同系同类语义）。rect 退行内联 Component + Loader 第三变体（删除 `_private/OctagonRectangleShape.qml`，不常驻内存）；退行组件不提供 fillItem 能力，fillItem 非空时 Loader 判定排除退行分支（cond1 已有）。圆角内弧半径由 Shape 自身从内环点计算（`|intRT − intTR|/√2` 等四角，control 不加派生属性）。**共享契约**：control 的 target 唯一（默认创建它的 QoolBox），共享 control 的组件需同一几何源（尺寸一致或自行设置 target）。
